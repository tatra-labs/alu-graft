What is running

  • Mellin ratio units. Banks of ~30 neurons with log-spaced gains compute v/r for two wires read at the same unknown RMSNorm scale. The scale cancels exactly, so every value comes back in absolute units.
  • Ramps. Pairs of SiLU neurons give thresholds that are exactly 0 below the cut, because the SiLU underflows. Carry-lookahead, borrows, digit selection and leading-zero stripping are all thresholds.
  • Offset heads. Qwen3 normalises every query and key per head, so a head built from a constant wire has a fixed logit scale. Its direction is optimised so that it reads exactly one relative offset, with a margin of 9 to 14 nats over 40,960 tokens.
  • Only A+B= and A-B= with 1–6 digit operands are supported, compact or spaced. Anything else, including chains, decimals, negatives, * and 7-digit numbers, leaves the circuit silent, and the base model writes whatever it would have.

Source, the full-model results and the method: github.com/tatra-labs/alu-graft. The idea comes from Sah, “A CPU Inside an LLM” (arXiv 2611.26450); this is an independent implementation.
